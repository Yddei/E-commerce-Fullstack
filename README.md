## How to Start:
1) Ensure you have Node.js, PostgreSQL installed
2) In the root project folder run npm install
3) [Create self-signed OpenSSL certificates](https://stackoverflow.com/questions/10175812/how-can-i-generate-a-self-signed-ssl-certificate-using-openssl)
4) Rename .env.example to .env
5) Change .env variables to suit your local machine
6) Run app.js

init.sql and .env file will create or assign the essential information to start the server
